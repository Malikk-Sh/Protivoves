# Противовес

Играбельный прототип оригинального 3D-экшена. Глава **«Нижние доки»** ведёт от учебной дуэли до победы над Доковым мастером и выхода к эвакуационной платформе. [ТЗ v1.1](Protivoves_GDD_TZ_v1.1.md) · [Визуальный альбом](Protivoves_Visual_References.pdf)

| Миссия | Задача |
|---|---|
| M01 «Сухой док» | Освоить замах и парирование в дуэли с Доковым сторожем |
| M02 «Грузовой проход» | Обойти контейнер, пробить защиту щитоносца сбоку и победить сторожа |
| M03 «Последний у трапа» | Очистить зону посадки и удержать её 26 секунд, пока выходят три волны |
| M04 «Доковый мастер» | Победить босса в двух фазах, пройти к платформе и открыть короткий тесак |

Карта открывает миссии по порядку. Доступны повторы, три сложности, выбор клинка и тренировка опоры. Звёзды, прогресс и настройки сохраняются в IndexedDB на текущем устройстве.

## Запуск

Нужны Node.js 24 или новее и браузер с WebGL 2. Используются TypeScript 7.0.2, Vite 8.3.8, Three.js 0.187.0 и Rapier 3D WASM 0.21.0.

```sh
npm ci
npm run dev
```

Откройте адрес из вывода Vite. Для проверки производственной сборки на телефоне в той же сети откройте `http://<адрес-компьютера>:4173` после следующих команд.

```sh
npm run build
npm run preview
```

Vercel устанавливает зависимости через `npm ci`, запускает `npm run build` и публикует `dist`. Серверные функции и переменные окружения игре не требуются.

## Управление

- В нижней половине экрана коснитесь пола и потяните палец. Для замаха сначала сделайте шаг, затем быстро доверните стик примерно на четверть оборота.
- На клавиатуре двигайтесь с помощью WASD или стрелок. Для замаха быстро смените направление, например с W на D. Нажмите пробел или отпустите стик после шага, чтобы вернуть клинок в стойку. Для парирования совместите это с движением вражеского клинка.
- Пауза доступна кнопкой в верхнем углу и клавишей Esc. После выполнения задачи пройдите через ворота, чтобы засчитать победу. Две дополнительные цели указаны на экране подготовки.
- На тренировке последовательно выберите «Устойчивая стойка» и «Перенос веса». Данил проводит одинаковую дугу. Фактический контакт отнимает 20 HP в обоих случаях. При двух опорных стопах сторож переступает, при одной падает и затем встаёт.

## Сцены и диагностика

Корневые капсулы, клинки, щит, ящики и настил работают в мире Rapier. Физика идёт с шагом 1/60 с, камера и позы интерполируются между тиками. При быстром повороте клинка геометрические запросы проверяют дугу по коротким сегментам. Контакты из решателя дополняют эту проверку в местах физического отскока.

В режиме разработки откройте `/?debug=1` и нажмите F2. Панель показывает затраты на тик, вызовы отрисовки и данные последнего контакта. Конфигурации миссий, противников, клинков и сложностей лежат в `src/content/campaign.ts`.

## Проверки

```sh
npm run typecheck
npm run test
npx playwright install chromium
npm run test:e2e
```

Для установленного Chromium можно задать `PROTIVOVES_CHROMIUM=/путь/к/chromium`. Браузерные тесты читают свежую производственную сборку из `dist`. Если задать `PROTIVOVES_SCREENSHOTS`, Playwright сохранит контрольные кадры в указанный каталог.

Симуляция проходит M01–M04 подряд на обычной сложности через тот же контроллер жестов. Отдельные проверки покрывают щит, таймеры и волны посадки, фазовый порог босса, объединение звёзд и открытие тесака. Браузерные проверки покрывают клавиатуру, эмуляцию касаний, поворот экрана, паузу, повтор и восстановление сохранения.

## Границы прототипа

Эта сборка охватывает первую главу. Данил и машины используют процедурные модели. При падении физика двигает корневую капсулу, а визуальная поза следует за ней. Замеры на реальных Android и iOS предстоят. [Авторы и лицензии](CREDITS.md)
